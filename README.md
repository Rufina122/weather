# Y2K Weather

Погода в реальном времени в стиле Y2K. Тема меняется вместе с погодой, а приложение можно установить прямо со страницы сайта (PWA).

**Стек:** Vite, Tailwind CSS v4, GSAP, vite-plugin-pwa, OpenWeather API.

## Запуск

```bash
npm install
cp .env.example .env     # впишите ключ OpenWeather
npm run dev              # разработка
npm run build            # сборка в dist/
npm run preview          # проверить сборку
```

Ключ берётся на https://home.openweathermap.org/api_keys (бесплатного тарифа хватает).
Новый ключ может активироваться до пары часов.
Без ключа сайт работает в демо-режиме: можно посмотреть все темы.

## Как это работает

- Погода и прогноз обновляются каждую минуту, а также при возврате на вкладку и появлении сети.
- Тема выбирается по коду погоды OpenWeather: солнце, облака, дождь, гроза, снег, туман, ночь.
- Приложение ставится кнопкой «Установить приложение». Установка работает только по HTTPS (или на localhost).

## Структура

- `src/main.js` — логика страницы, обновление, поиск
- `src/api.js` — запросы к OpenWeather и демо-данные
- `src/fx.js` — фоновые эффекты (дождь, снег, звёзды и т. д.)
- `src/icons.js` — иконки погоды и список тем
- `src/install.js` — кнопка установки приложения
- `src/style.css` — темы и стиль Y2K
